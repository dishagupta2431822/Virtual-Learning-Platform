4. Valence Electron Rule Guide

  • s/p Block: Outer shell (n) electrons.
  • d-Block: (n-1)d + ns electrons (e.g., Sc = 1d + 2s = 3 e⁻).
  • f-Block: (n-2)f + (n-1)d + ns electrons (e.g., Ce = 1f + 1d + 2s = 4 e⁻).
