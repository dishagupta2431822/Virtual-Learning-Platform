Tutorial & Theory

Universal Gate Principles

Universal Gates (NAND and NOR) are special logic gates because any boolean function or digital logic circuit can be constructed using *only* NAND gates or *only* NOR gates.

NAND Gate Property

Not-AND produces a LOW (0) output only when both inputs are HIGH (1). Otherwise, output is HIGH.

NOR Gate Property

Not-OR produces a HIGH (1) output only when both inputs are LOW (0). Any HIGH input forces output to LOW.

Experiment Objectives

  • Verify De Morgan's Laws using NAND and NOR configurations.
  • Construct virtual NOT, AND, and OR gates using solely NAND inputs.
  • Measure voltage propagation delays and inversion behavior.
