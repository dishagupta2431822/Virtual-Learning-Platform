Tutorial & Theory

Step-by-step guidance

Logic gates are electronic circuits built from transistors that perform basic Boolean logic functions. They are the fundamental building blocks of digital integrated circuits (ICs) and microprocessors.

AND Gate Rule

The output is HIGH (1) only if both Input A and Input B are HIGH. Otherwise, the output is LOW (0).

OR Gate Rule

The output is HIGH (1) if either Input A or Input B (or both) are HIGH. Output is 0 only when both inputs are 0.

Experiment Objectives

  • Verify truth table combinations for AND gates.
  • Switch to OR gate mode and verify disjunctive logic.
  • Analyze voltage states and signal propagation.
