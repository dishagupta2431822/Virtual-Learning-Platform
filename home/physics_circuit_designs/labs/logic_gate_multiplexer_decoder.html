Tutorial & Theory

Combinatorial Logic Chips

A Multiplexer (MUX), or data selector, routes one of several digital input lines to a single output line based on binary select lines ($S_1, S_0$).

4:1 Multiplexer

Has 4 data inputs ($I_0-I_3$), 2 select lines ($S_1, S_0$), and 1 output ($Y$). The address $(S_1 S_0)_2$ selects which input propagates to $Y$.

1:4 Demultiplexer

Reverses the process: routes a single input signal $D$ to one of 4 output channels ($Y_0-Y_3$) selected by address lines ($S_1, S_0$).

Experiment Objectives

  • Understand data selection and routing using AND-OR logic gates.
  • Verify 4:1 MUX and 1:4 DEMUX truth tables under active select addresses.
  • Trace high/low digital logic levels across combinational paths.
